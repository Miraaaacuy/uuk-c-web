Mengenal TypeScript untuk Pemula

TypeScript adalah bahasa pemrograman yang dikembangkan dari JavaScript. Kelebihannya adalah adanya tipe data yang jelas seperti number, string, dan boolean, sehingga kesalahan dalam kode dapat ditemukan sebelum program dijalankan.

Kode TypeScript tidak dapat langsung dijalankan di browser. Kode tersebut harus diubah terlebih dahulu menjadi JavaScript dengan perintah tsc. Karena itu, TypeScript banyak dipakai untuk membuat aplikasi web yang besar dan rapi.
